# Eveo BDC

A full-stack SaaS platform dedicated to the operational management of automotive BDCs. 

## Tech Stack
* **Frontend:** React, TypeScript, Vite, Tailwind CSS v4
* **Backend:** Node.js, Express, MongoDB
* **Third-Party Integrations:** NHTSA vPIC API, OpenAI API

## Architecture
This project uses a decoupled client/server architecture. The frontend is initialized with Vite and uses a strict Pull Request-driven Git workflow.
